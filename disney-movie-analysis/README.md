# Disney Movie Financial Analysis

## Overview

This project analyzes the financial performance of Disney movies across multiple decades. The analysis examines 575 Disney films released between 1937 and 2016 to investigate patterns in inflation-adjusted box-office revenue and determine whether particular decades demonstrated stronger financial performance.

## Research Question

How has Disney's inflation-adjusted box-office performance varied across decades, and was the financial performance of films released during the 1990s significantly different from films released during the 2000s?

## Methods

The project uses exploratory data analysis and statistical methods to evaluate historical movie performance, including:

- Data cleaning and preparation
- Exploratory data analysis
- Data visualization
- Correlation analysis
- Hypothesis testing
- Regression analysis

## Tools

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings

The analysis identified strong inflation-adjusted box-office performance during both the 1990s and 2000s. A statistical comparison produced a p-value of approximately 0.083, which did not provide sufficient evidence to conclude that the 1990s significantly outperformed the 2000s at the 0.05 significance level.

Regression analysis explained approximately 41% of the observed variation in revenue, indicating that additional factors beyond the variables included in the model contribute to movie financial performance.
