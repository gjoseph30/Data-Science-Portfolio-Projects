## Projects

### 1. Airline Delay Analysis & Prediction

Analyzed approximately 6.9 million U.S. airline flights from 2025 to identify patterns associated with arrival delays and evaluate whether pre-flight information could predict flights arriving at least 15 minutes late.

Logistic Regression and Random Forest models were compared using recall, F1 score, and ROC-AUC in addition to accuracy. Random Forest provided the stronger overall discrimination, while feature importance identified scheduled arrival and departure times as the strongest predictors.

**Skills:** Large-Scale Data Analysis, Random Forest, Logistic Regression, Classification, Feature Engineering, Model Evaluation

[View Project](./airline-delay-prediction)

### 2. ALS Patient Segmentation

Applied unsupervised machine learning to clinical ALS data to explore whether patients could be grouped according to similarities in their characteristics.

K-Means clustering was evaluated using silhouette analysis, and PCA was used for dimensionality reduction and visualization. The analysis also demonstrated the importance of interpreting weak cluster separation rather than assuming algorithmically generated clusters represent meaningful patient subtypes.

**Skills:** K-Means Clustering, PCA, Unsupervised Learning, Patient Segmentation, Feature Scaling

[View Project](./als-patient-segmentation)

### 3. Customer Churn Big Data Analytics

Developed an end-to-end big data analytics pipeline for customer churn analysis using multiple Hadoop ecosystem technologies.

The workflow integrated Apache NiFi for ingestion, HDFS for distributed storage, Hive for SQL-based querying, Spark MLlib for Logistic Regression modeling, and HBase for storing and verifying model results.

**Skills:** Hadoop, Apache NiFi, HDFS, Hive, Spark MLlib, HBase, PySpark, Data Engineering

[View Project](./customer-churn-big-data)

### 4. Disney Movie Financial Analysis

Analyzed the financial performance of 575 Disney films released between 1937 and 2016, with emphasis on inflation-adjusted box-office revenue and differences in financial performance across decades.

The project incorporated exploratory analysis, visualization, hypothesis testing, correlation analysis, and regression modeling to evaluate historical movie-performance patterns.

**Skills:** Statistical Analysis, Hypothesis Testing, Regression, Exploratory Data Analysis, Data Visualization

The project included extensive data preprocessing, missing-value analysis, categorical encoding, feature preparation, Random Forest classification, and evaluation using metrics appropriate for an imbalanced healthcare outcome.

**Skills:** Healthcare Analytics, Random Forest, Classification, Data Cleaning, Feature Engineering, Model Evaluation

Developed a time-series forecasting workflow using monthly U.S. retail sales data from 1992 through 2021.

The analysis examined long-term trend, seasonal behavior, and COVID-era disruption. A seasonal SARIMAX model was trained using historical observations and evaluated against a 12-month holdout period.
